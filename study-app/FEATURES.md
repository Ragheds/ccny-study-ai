# Feature status

## Available now

- Supabase email authentication and account deletion endpoint
- CCNY major and course selection from a 2,083-course catalog
- Streaming course-aware AI tutor with saved chats
- Generated flashcards, quizzes, quiz review, and progress history
- Per-course editable notes and AI summaries
- Browser text-to-speech explanation for quiz answers
- Light and dark themes
- Signed-in tutor access, server-enforced quota, and AI usage records (once the Phase 0 SQL migration is applied)
- Supabase-backed major, courses, notes, flashcards, and quiz data with server-rendered workspace state (after the Phase 1 SQL migration)

## Planned

- Study-mode preferences and a per-item offline sync queue
- Offline course packs and installable PWA service worker
- Material-grounded packs from uploaded PDFs or pasted text
- Whiteboard lessons, code mode, and voice conversation
- Billing and beta analytics

Current saved learning data is browser-local. Upload text used in a tutor prompt is not yet a persistent private document library.
